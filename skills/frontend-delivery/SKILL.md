# frontend-delivery

입력: UI 여정·API 계약·디자인 토큰. 정상/빈/오류/권한/부분 실패·키보드·light/dark를 구현한다. 실제 인증/SSE/WS/E2E를 확인한다. 내부망 web image/digest·proxy·HTTPS·rollback·smoke Evidence를 제출한다. secret은 client bundle에 넣지 않는다.

권한: 현재 사용자 지시와 실행 환경 권한 범위 안에서 동작한다. 이미 승인된 작업의 반복 확인을 요구하지 않는다. 공통 지침은 AGENTS.md다.
