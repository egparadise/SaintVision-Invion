# S01 물리 노드 5대 인벤토리 표 양식

[[2026-09-22_S01-BE_S01-ST_잔여_합격조건표_Claude]] "우리 몫 2"(인벤토리 표 양식 + 미확인 값 열). AC-01 기준 "5노드 조사표의 **미확인 값 명시**"를 충족하려면 값을 채우기 전에 **무엇을 물어야 하고, 어디서 오고, 무엇이 아직 모르는지**가 표에 있어야 한다. 이 문서는 **양식**이다 — 값은 전부 미기재이며, 사용자가 U1(토폴로지)·U5(물리 PC)를 줄 때 채운다([[S02_선행입력_체크리스트_2026-09-22]] §0·§4). 등록 후에는 커널 관측(`GET /v1/projects/{p}/nodes/{n}`의 capability, `NodeResourceUsage`)과 **대조**해 인벤토리 값이 자기신고가 아니라 관측과 일치함을 확인한다.

## 0. 먼저 — 토폴로지 결정(U1)에 따라 표의 행 수가 정해진다

| 결정 | 행 | 비고 |
|---|---|---|
| 5 worker + 별도 CP(권고) | Node 5행 + CP 1행(관측 대상 아님, 접근 정보만) | registry·S02 인수 기준 유지 |
| 1 CP 겸 Node + 4 worker | Node 4행(+겸임 1행 별도 표기) | S02/S05/S12 "5대" 기준 재정의 필요 |
| CP 겸임 유지 | 5행 + 겸임 표시 | 별도 ADR |

## 3. 비밀·원문 금지
cert 개인키·discovery credential 원문·DSN·비밀번호는 이 표에 **절대 적지 않는다**(지문·ID·만료일만). 표는 `docs/vault`(Git)에 있으므로 값이 들어가는 순간 공개 이력이 된다 — 값이 필요한 열은 별도 보호 저장소 경로만 적는다.

## 4. 채우는 순서
1. U1 결정 → 행 수 확정. 2. 사용자가 A·B·C·D·G를 자기신고로 채움(모두 ☑ 미확인). 3. 운영 CA·운영자 CLI로 E 채움. 4. Node 1대 설치·등록 → H1 관측 → B·D를 capability/skew와 대조해 ☐ 전환(H2). 5. 나머지 4대 반복. 6. 남은 ☑가 S01-ST 인수 증거의 "미확인 값 목록"이 된다.
