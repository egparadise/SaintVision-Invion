# S01 Node 인벤토리 실측 초안 (2026-09-28, 읽기 전용 측정)

[[S01_물리노드_인벤토리_표양식_2026-09-22]](PR #55 양식)에 **관측 가능한 사실만** 채운 초안이다. 대상은 LAN 파일럿 private state(`.work/lan-5node/node1`, 읽기 전용)에 등록된 Node와 코디네이터가 말한 미등록 4번째 PC다. **허용 자원 상한(C1)·허용 폴더(C2)·Storage 역할(G1)·역할/토폴로지(A6·§0)는 사용자 결정이라 비워 둔다.** 측정하지 못한 칸은 `미확인`, 결정 칸은 `사용자 결정`으로 적고 추정값은 넣지 않는다(조용한 강등 금지).

> [!note] 문서 정책(IP·hostname·비밀)
> - **IP**: 사설 서브넷의 마지막 옥텟만 `<lan>.N`으로 적는다(서브넷은 private state에만). #122 preflight가 보고서에서 `ip`/`hostname` 값을 금지 키로 두는 방향과 맞추되, 행을 식별할 수 있게 옥텟은 남긴다. 전체 값은 Git 밖 보호 inventory JSON에만 둔다.
> - **hostname**: 비밀이 아니므로 OS가 보고한 값을 그대로 적는다(A1 요구). 개인 계정명이 포함된 경우 사용자가 원하면 후속에서 마스킹한다.
> - **비밀**: DSN·비밀번호·키·인증서 원문·SSH 키 지문은 적지 않는다(양식 §3). Node ID·이미지 digest·machine-id의 sha256 앞 16자리만 적는다.

## 2. 이 초안이 보여주는 것 / 못 보여주는 것

- **측정됨**: 등록 3 Node의 CP 관측값(S-2), Node-3의 하드웨어·OS·Docker·NTP 전부(S-3). Node-3는 인벤토리 ↔ capability가 CPU·RAM에서 정확히 일치한다(H2).
- **미확인**: Node-1·Node-2의 호스트 내부 사실(SSH 키가 그 호스트의 시험 계정에 승인되지 않음 — **계정명은 사용자 결정 U5의 일부**), Node-2 offline 원인, Node-4의 존재 확인(state·PG·SSH 어디에도 없음), 모든 Node의 인증서·CA·credential(E), NIC 대역폭·지연(B5).
- **사용자 결정으로 비움**: U1 토폴로지(행 수·CP 겸임), A2 DNS, A6 역할, C1 상한, C2 폴더, F2, G1.
- **관측 한계**: `lan-observe-v1` snapshot은 `cpuCapacityMillis`·`memoryCapacityBytes`만 싣는다. GPU·storage·network capability는 `inv.resources`(offer 승인 뒤)에서만 나오므로, C1 결정 전에는 H2 대조가 CPU·RAM으로 제한된다.
