# 개발 과정 기록 템플릿

파일명: `YYYY-MM-DD_HH-mm-ss_KST_taskID_Agent_개발과정.md`. 미래 시각은 생성하지 않는다.

- record_id / task_id / sprint / area / agent / reviewer:
- started_at / ended_at / timezone(Asia/Seoul):
- status(planned/ready/in_progress/review/done/blocked):
- objective / outcome_id / acceptance_id:
- 기준 문서 ID·버전 / base_sha / branch / 범위:
- init 확인(권한·git status·선행 작업·Skill):
- 변경 내용 / 영향 계약 / 실제 파일:
- 검증 명령·exit code·표본 수·실제 결과·Evidence 경로:
- implementation_commit / report_commit(자기 참조 제외):
- push(remote/branch/result) / CI(run_id/url/status):
- Obsidian report(대상·hash·동기화 결과):
- 오류 링크 / 해결 링크 / 알려진 제한:
- 다음 담당자·작업·인계 상태:

미실행은 `not_run`, 확인 불가는 `unknown`, 실패는 `failed`로 기록한다. 예상 명령과 실행한 명령을 구분한다.
