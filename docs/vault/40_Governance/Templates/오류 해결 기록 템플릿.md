# 오류 해결 기록 템플릿

파일명: `RES-YYYYMMDD-HHMMSS-errorID_해결.md`.

- resolution_id / error_id / resolved_at / agent / reviewer:
- 원인과 확정 근거 / 변경 사항:
- resolution_scope(design_documentation/runtime_implementation):
- fix_commit / 실제 재현·회귀 검증 명령·결과:
- 검증 Evidence / build 결과 / rollback:
- 재발 방지 / 잔여 제한 / 다음 담당자:

문서에 정정했다고 제품 코드의 오류가 해결됐다고 표시하지 않는다. 실행 검증 전에는 runtime_verified=false를 명시한다.
