# 오류 기록 템플릿

파일명: `ERR-YYYYMMDD-HHMMSS-taskID_요약.md`.

- error_id / occurred_at / task_id / agent / severity:
- 종류(design/runtime/environment/documentation):
- 영향 영역 / 사용자 영향 / 재현 환경:
- expected / actual / 재현 순서:
- source_ref / code_commit / trace_id / evidence_ref:
- 원인 확정 여부 / 가설과 근거:
- 담당자 / 상태(open/investigating/resolved/reopened):
- 해결 페이지 링크 / next_action:

설계 결함 발견을 실제 제품 장애라고 쓰지 않는다. 원문 비밀·presigned URL·환자 데이터를 로그에 붙이지 않는다.
