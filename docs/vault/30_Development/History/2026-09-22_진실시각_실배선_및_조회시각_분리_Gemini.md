  2. **진실 시각 제공 대상 실배선**:
     - 노드: `lastHeartbeatAt` 물리 생존 신호 시각 표출 (`ClusterOverview`, `ResourceExplorer`).
     - 복제본/스토리지: `observedAt` (관측 시각) 및 `createdAt` (요청 생성 시각) 표출 (`ResourceExplorer`). **[불변 계약 준수]**: `currentHealth: "unknown"`, `operationalAcceptanceAssessed: false`로 못 박혀 있으므로 "건강 상태 단언 유보 고지(실행 시점 재검증 필수)"를 명확히 병기하여 "지금 건강"으로 오독되는 것을 원천 차단.
     - 실행 결과: 종단(`succeeded`, `failed`)일 때 `updatedAt` / `completedAt` 표출 (`RunDetail`, `RunList`).
     - 모델 커밋: `committedAt` 표출 (`ModelStudioView`). 부재 시 가짜 현재 시각(`new Date().toISOString()`)으로 합성하던 타임스탬프 위조 소거.
     - 실행 시도: 항목별 `startedAt` 표출 (`RunDetail` Attempts 탭).
  3. **진실 시각 미제공 대상의 조회 시점 명시**:
     - 라이브 실행 상태, `ShardObservation`(샤드 상태), `RunArtifactList`, `RunLogView`: 백엔드가 `observedAt`를 주지 않으므로, 화면의 `lastFetchedAt`를 마치 데이터 진실 시각인 양 꾸미지 않고 **"화면 확인 기준(조회 시점)"**임을 정직하게 못 박음.
  4. **사실(Fact) vs 판단(Judgement)의 엄격한 분리**:
     - 시각을 보여주는 것은 사실이고 오래되었다고 말하는 것은 판단임.
     - 실측 보정 임계값(Threshold) 계약이 없는 상태에서 자의적인 "오래된 정보 주의" 낙인을 제거하고, "동기화 실패 사실"과 "화면 확인 시점 스냅샷 시각"을 건조하게 제시하여 판단은 사용자에게 맡김.
  5. `EvidenceViewer`: 클립보드 복사 시 브라우저 `alert()`을 소거하고 `copy-evidence-success` 인라인 피드백(`role="status"`)으로 정합, `generatedAt` 위조 차단.

## 1. 세부 구현 및 계약 정합

### A. `ClusterOverview.tsx` (대시보드 진실 시각 표출 및 사실형 어휘 정규화)
1. **조회 시점 사실 표기**:
   - 상단 헤더 신선도 문구를 `🔄 자동 갱신 (5초 주기) · 화면 확인: HH:mm:ss`로 정규화 (`data-testid="cluster-freshness-indicator"`).
   - 동기화 실패 시 배너 문구를 `⚠️ [동기화 실패] 클러스터 노드 동기화에 실패했습니다 (...). 현재 표시된 노드 정보는 HH:mm:ss 화면 확인 시점 스냅샷입니다.`로 정규화 (주관적 낙인인 "오래된 정보 주의" 소거).
2. **물리 노드 생존 신호 진실 시각 표출**:
   - 물리 노드 카드 및 텔레메트리 결측 노드 목록에 `node-heartbeat-${node.id}` 표출:
     `마지막 하트비트: {node.heartbeatAt ? new Date(node.heartbeatAt).toLocaleTimeString('ko-KR') : '미관측 (Heartbeat Absent)'}`
3. **runs 기본값 방어**:
   - `runs = []` 기본값 처리로 텔레메트리 결측 상태 렌더링 시 크래시 방지.

### B. `ResourceExplorer.tsx` (자원 탐색기 노드·스토리지 진실 시각 및 건강 단언 유보 고지)
1. **상단 동기화 시각 정규화**:
   - `data-testid="node-freshness-notice"`: `🔄 클러스터 노드 동기화 (5초 주기) · 화면 확인: HH:mm:ss`
2. **오버뷰 노드 카드 및 Tab 4 노드 상세 하트비트 진실 시각**:
   - 오버뷰 노드 카드: `data-testid="node-card-heartbeat-${node.id}"`
   - Tab 4 노드 상세: `data-testid="node-detail-last-heartbeat"` (`마지막 하트비트: HH:mm:ss` 또는 `미관측 (Heartbeat Absent)`)
3. **Tab 2 스토리지 관측 진실 시각 및 건전성 단언 유보 고지**:
   - `storage-observation-created-at`: 요청 생성 시각 (`storageObservation.createdAt`)
   - `storage-observation-observed-at`: 표본 관측 시각 (`new Date(storageObservation.observation.observedAt * 1000).toLocaleString('ko-KR')`)
   - `storage-observation-health-disclaimer` (`role="status"`):
     `⚠️ [건강 상태 단언 유보 고지]: 위 관측 시각은 스토리지 표본 무결성 검증 시점이며 현 시점 라이브 가용성을 보증하지 않습니다. ADR-028/041 계약에 따라 currentHealth: "unknown" 및 operationalAcceptanceAssessed: false로 유지되며, 분산 실행 시점 재검증이 필수적입니다.`

### C. `RunDetail.tsx` (종단 완료 시각 실배선 및 미제공 탭 화면 확인 기준 고지)
1. **헤더 진실 시각 표출**:
   - `data-testid="run-detail-created-at"`: 생성 시각
   - 종단 상태(`succeeded` / `failed`)일 때: `data-testid="run-detail-completed-at"` (`종료: HH:mm:ss` 또는 `미관측 (UpdatedAt Absent)`)
2. **백엔드 관측 시각 미노출 탭의 정직한 화면 확인 기준 고지**:
   - Tab 2 실시간 로그: `data-testid="logs-query-time-notice"` (`role="status"`, `ℹ️ [화면 확인 기준] 실시간 커널 로그는 백엔드 관측 시각(observedAt) 미노출 상태이며, 화면 수신 시점 기준입니다.`)
   - Tab 3 산출물: `data-testid="artifacts-query-time-notice"` (`role="status"`, `ℹ️ [화면 확인 기준] 산출물 목록은 백엔드 관측 시각(observedAt) 미노출 상태이며, 화면 조회 시점 기준입니다.`)
   - Tab 5 분산 샤드: `data-testid="shards-query-time-notice"` (`role="status"`, `ℹ️ [화면 확인 기준] 분산 샤드 실행 원장은 백엔드 관측 시각(observedAt) 미노출 상태이며, 표시된 정보는 화면 조회 시점 기준 스냅샷입니다.`)

### D. `RunList.tsx` & `ApprovalCenter.tsx` (사실 기반 어휘 및 종단 시각 실배선)
1. **RunList**:
   - 상단 헤더: `🔄 자동 갱신 (5초 주기) · 화면 확인: HH:mm:ss`
   - 동기화 실패 배너: `⚠️ [동기화 실패] ... 화면 확인 시점 스냅샷입니다.`
   - 테이블 각 행: `data-testid="run-created-at-${run.id}"` 및 종단 완료 시 `data-testid="run-completed-at-${run.id}"`
2. **ApprovalCenter**:
   - 상단 헤더: `🔄 자동 갱신 (5초 주기) · 화면 확인: HH:mm:ss`
   - 동기화 실패 배너: `⚠️ 승인 목록 동기화 실패 ... 화면 확인 시점 스냅샷입니다.` (주관적 낙인 '신선도 저하 주의' 소거)

### E. `ModelStudioView.tsx` & `EvidenceViewer.tsx` (가짜 타임스탬프 합성 소거 및 alert() 제거)
1. **ModelStudioView**:
   - `result.committedAt` 부재 시 `new Date().toISOString()`을 합성하던 가짜 fallback을 소거하고 `미관측 (CommittedAt Absent)`으로 정직화 (`data-testid="model-committed-at"`).
   - `result.sourceRunId` 부재 시 `run_source_verified`를 조작하던 fallback을 소거하고 `미지정 (Run ID Absent)`으로 정합.
2. **EvidenceViewer**:
   - `generatedAt` fallback에서 `new Date().toISOString()` 소거.
   - 클립보드 복사 버튼 클릭 시 호출되던 브라우저 `alert()`을 제거하고 `data-testid="copy-evidence-success"` 인라인 상태(`role="status"`)로 전환.
