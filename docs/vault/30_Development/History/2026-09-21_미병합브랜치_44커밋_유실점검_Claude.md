## 방법 (제목만 보지 않고 내용 확인)
- 고정 tip **`938ea1b`**(점검 중 integration이 이동 — 이 SHA로 못 박음). 인터프리터 무관(git만).
- **① `git cherry -v tip branch`**: `-`=동일 patch가 이미 upstream(=cat1 확정). `+`=동일 patch 없음(내용은 다른 경로로 들어갔을 수 있어 추가 확인 필요).
- **② 산출물 존재 확인**: `+` 커밋이 만든 파일/함수/시험이 tip에 **실재하는지** `git cat-file -e`/`git grep`.
- **③ 내용 수렴 확인**: 기존 파일 수정 커밋은 `git diff tip branch -- file` 줄 수. 0=동일(cat1). **주의**: `review/*`는 tip보다 **96 커밋 뒤**라 diff가 커도 대부분 integration의 **전진 진화**지 브랜치-단독 내용이 아니다 — 방향(누가 신규 도입했나)으로 판정.
- 3갈래: **(1) 이미 들어감**(다른 경로/후속으로 내용 존재) · **(2) 안 들어갔고 필요**(조용한 손실) · **(3) 안 들어갔고 불필요**(자체 대체·전제 변경).
