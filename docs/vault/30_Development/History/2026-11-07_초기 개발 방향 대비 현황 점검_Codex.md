# 2026-11-07 초기 개발 방향 대비 현황 점검

제품 방향은 초기 계획에 부합한다. 다만 개별 코드·보안 검증에 비해 실제 장비와 전체 사용자 여정의 인수 증거가 뒤처져 있다. 필수 보안·무결성 게이트를 유지하면서 **한 Node의 등록·자원 표시·격리 실행·결과와 감사 확인**을 먼저 연결하고, 이어 5대 자원·GPU·분산 저장·장애 복구를 증명하는 순서가 필요하다. 관측하지 않은 기능을 미구현이라고 단정하거나, 좁은 코드 수락을 전체 완료로 집계하지 않는다.

## 초기 목표와 범위

## 실제 장비 차단과 첫 실행 순서

- PC1: 공개키 SSH 인증이 거부됐다. 관측 실패이며 키 파일 자체가 없다는 뜻은 아니다.
- PC2~4: 호스트 GPU 조회는 성공했지만 컨테이너 GPU 사용은 시험하지 않았다. toolkit/runtime 명령·nvidia runtime·CDI spec도 확인되지 않았다. 측정 전에는 GPU 사용 가능량으로 집계하지 않는다.

1. 필수 코드 결함·권한 경계와 통합에 필요한 증거를 먼저 닫는다. 비차단 선택적 Low/INFO는 백로그로 관리하고 자동으로 새 릴리스 필수조건이나 반복 재검토 카드로 확대하지 않는다. H12C-L1은 DER 경계의 인과 시험 보강이며 현재 수락된 코드의 필수수정은0이다.
