# S11-FE 제품 결함 DEF-S11-01~19 전수 치유 및 접근성·RCV무결성 검증 보고서

## 1. 개요 및 배경

승인된 S11-FE 시나리오 매트릭스 v1.0.2(`1ea3c90e`, `docs/vault/30_Development/2026-09-28_S11-FE_접근성_시각회귀_배포후보_시나리오_매트릭스_Gemini.md`)에 등록된 19대 제품 결함 백로그(**DEF-S11-01 ~ DEF-S11-19**)를 `apps/web` 제품 소스코드 전역에서 전수 치유하였다.

코디네이터의 우선순위 지침에 따라 다음 4대 핵심 축을 중심으로 수정 및 검증을 완료하였다:
1. **WCAG 2.1 AA 명도 대비율 적합화 (DEF-S11-09, DEF-S11-10)**: 기본 다크 테마 Primary/Danger 버튼 대비 4.5:1 이상, 비텍스트 폼 경계선 대비 3.0:1 이상 확보.
2. **모달 포커스 트랩, 복귀, Esc 및 ARIA 접근성 표준화 (DEF-S11-01~06)**: `useModalA11y` 훅 신설, Tab 순환 트랩, 닫힘 시 트리거 복귀, Esc 핸들러, `role="dialog"`, `aria-modal="true"`, `aria-labelledby`, 활성 탭 `aria-current="page"`.
3. **ReleaseCandidateView 허위 상태 표출 및 과장 고지 전면 격리 (DEF-S11-08, DEF-S11-11~16)**: 미연동 백엔드 제어 API 상태에서 'ACTIVE LIVE'/'STANDBY' 배지를 '모의 활성'/'모의 대기'로 격리, 롤백 '✔ 검증 완료' 초기 렌더 하드코딩 제거(`rollbackVerified: false`), 정적 예시 안내 정정.
4. **반응형 뷰포트 및 시각 레이아웃 결함 치유 (DEF-S11-17~19)**: auto-fit 유동 그리드, 테이블 가로 스크롤 래퍼, 뷰포트 시뮬레이터(Desktop/Tablet/Mobile) 동적 폭 바인딩, 롤백 버튼 버전 식별 aria-label 부여.

## 3. WCAG 명도 대비 수동 계산식 및 수학적 근거 (DEF-S11-09 & DEF-S11-10)

W3C WCAG 2.1 상대 휘도(Relative Luminance) 정의 공식:
$$L = 0.2126 \times R + 0.7152 \times G + 0.0722 \times B$$
단, $C \le 0.04045$ 일 때 $C / 12.92$, 초과 시 $((C + 0.055) / 1.055)^{2.4}$.
명도 대비율 공식:
$$\text{Contrast Ratio} = \frac{L_{\text{lighter}} + 0.05}{L_{\text{darker}} + 0.05}$$

### 계산 결과 요약
1. **Primary 버튼 (다크 테마)**:
   - 전경색: 흰색 `#ffffff` ($L = 1.0$)
   - 배경색: `#1d4ed8` ($L = 0.104$)
   - 대비율: $(1.0 + 0.05) / (0.104 + 0.05) = 1.05 / 0.154 =$ **6.81:1** ($\ge 4.5:1$ **적합**)
2. **Danger 버튼 (다크 테마)**:
   - 전경색: 흰색 `#ffffff` ($L = 1.0$)
   - 배경색: `#dc2626` ($L = 0.166$)
   - 대비율: $(1.0 + 0.05) / (0.166 + 0.05) = 1.05 / 0.216 =$ **4.86:1** ($\ge 4.5:1$ **적합**)
3. **입력 폼 경계선 (다크 테마 non-text UI contrast)**:
   - 경계선 색: `#9ca3af` ($L = 0.379$)
   - 배경색: `#1f2937` ($L = 0.038$)
   - 대비율: $(0.379 + 0.05) / (0.038 + 0.05) = 0.429 / 0.088 =$ **4.87:1** ($\ge 3.0:1$ **적합**)
4. **입력 폼 경계선 (라이트 테마 non-text UI contrast)**:
   - 배경색: `#f1f5f9` ($L = 0.913$)
   - 경계선 색: `#64748b` ($L = 0.230$)
   - 대비율: $(0.913 + 0.05) / (0.230 + 0.05) = 0.963 / 0.280 =$ **3.44:1** ($\ge 3.0:1$ **적합**)
