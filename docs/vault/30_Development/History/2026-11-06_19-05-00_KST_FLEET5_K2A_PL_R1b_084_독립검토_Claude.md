### accept한 부분

- **쓰기 형태:** AssignStmt(tuple, select-case 포함), `Tok==ASSIGN`인 RangeStmt의 Key/Value, IncDecStmt를 모두 모은다. GoStmt/SendStmt 거부와 builtin allowlist(append/len/make)를 합치면, Go 문장 수준의 쓰기 형태를 덮는다.
- **외부 변수:** object identity로 판정한다. 괄호, dot import, 별칭 import를 포함하며, 철자 heuristic은 쓰지 않는다.
- **주소 경로:** Paren/Star/Index/Slice/Selector를 root까지 내려간다.
  - Selector는 go/types `Selection.Index()` field 경로를 따른다. 명시·암묵·promoted 역참조를 모두 포함한다.
  - 검토자가 새로 만든 거부 7건(R1–R7)이 모두 의도한 사유로 거부됐다:
    - `&`로 받은 지역 이중 역참조
    - type assertion 역참조
    - generic `*T`
    - `&외부field`(builtin int)
    - 호출하지 않은 closure
    - own→외부 promoted pointer
    - own 이름 pointer가 가리키는 unnamed array
- **7건 escape:** 깨끗한 484 실행에서 7건 모두 의도한 사유로 거부됐다.
- **PL-I3:** 음성 case 54건 모두가 사유 prefix에 묶여 있다. 사유 계약이 없는 음성 case는 실패한다.

### PL-R1c (LOW, 제품 동작은 막지 않음): pointer 변환으로 pointee 타입 세탁

- **원인:**
  - `sourceEffects`는 타입 변환 호출을 검사 없이 통과시킨다(`effect_gate_test.go:371-373`).
  - `ownPointeeWrite`는 pointee가 자체 패키지의 이름 타입이면 허용한다.
  - 그래서 외부 타입 위에 자체 이름 타입을 정의하면 같은 주소를 자체 타입으로 바꿔 쓸 수 있다.
- **반례:** compile-valid 6건이다. 모두 build exit 0이고, 현재 484 gate가 nil을 반환한다.
  1. `type plLaunder clock.Location; *(*plLaunder)(clock.UTC)=plLaunder{}`
  2. 함수 지역 `type L clock.Location`을 거친 `p:=(*L)(clock.UTC); *p=L{}`
  3. 자체 method `(*L).reset` 경유(`Time{}.Location()`)
  4. `type C x509.Certificate; (*C)(c).Version++`
