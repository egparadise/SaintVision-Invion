## 1. 개요
- 5시간 자율 연속 실행 트랙(총 4시간 20분 소요, 2026-09-21 21:30 ~ 2026-09-22 01:50 KST) 동안 화면(Frontend) 전역에서 누적되었던 구조적 결함들을 10대 축에 걸쳐 체계적으로 치유하고, 이를 7대 스캐너 규칙과 9대 한계로 영구 고정함.

## 2. 오늘 밤 완결된 화면 10대 치유 축

1. **합성 제거 (Anti-Synthesis)**:
   - `mlopsEngine.ts` 가짜 모델 계보/정확도 지표 합성 제거 (`apps/web/tests/fixtures/model-lineage.ts`로 격리).
   - `StorageObservationView` 임의 `healthy: true` 합성 금지 (`currentHealth: "unknown"`, `operationalAcceptanceAssessed: false` 정직 노출).
   - `RunDetail.tsx` 가짜 SSE 스트림 로그 날조 제거 ➔ 정직한 빈 상태 표시.
   - `DeveloperStudio.tsx` fallback runId 및 `res.completedAt || new Date().toISOString()` 타임스탬프 위조 전소.
2. **죽은 방어 살리기 및 0-Call 가드 (0-Network Calls Without Basis)**:
   - 필수 인자 부재 시 임의의 더미값 전송 금지, 네트워크 호출 0회 차단.
   - `ResourceExplorer.tsx` 테넌트 부재 시 안내 방송 차단 (`!tenantId`).
   - `WebTerminal.tsx` 승인 명령 부재 시 일회용 티켓 발급 차단.
   - `ModelLineageView.tsx` 승인 입력 부재 시 배포 차단.
   - `DeveloperStudio.tsx` 활성 실행 부재 시 영수증 조회 차단.
3. **조기 성공 표시 제거 (No Premature Success)**:
   - `WebTerminal.tsx` 소켓 연결 수립 전 초기 버퍼 `Connected` 출력 제거 (실제 `onopen` 콜백 이후 출력).
   - `WebTerminal.tsx` 1회용 티켓 토큰 콘솔 로깅 원천 금지 (Zero-Leak Invariant).
   - `InvFileExplorer.tsx` 클라이언트 타이머 기반 가짜 복구 시뮬레이션 제거.
   - `ReleaseCandidateView.tsx` 롤백 허위 축하 배너 제거 ➔ `[모의 시뮬레이션]` 정직 고지.
4. **가짜 식별자 전면 소거 (No Synthetic Placeholders)**:
   - `00000000-0000-0000-0000-000000000001` (가짜 테넌트 UUID), `run_01JABCDEF_DEMO`, `apr_01JXYZ889900`, `prj_01JABCDE`, `wsp_0123456789ABCDEFGHJKMNPQRS`, `usr_admin_01`, `usr_operator_lead` 전소.
   - 실제 인증 세션(`currentUser.tenantId`, `currentUser.id`) 및 실제 프로젝트/체크아웃 컨텍스트 실배선.
5. **엄격한 3상태 무결성 확립 (Strict Tri-State: unverified ≠ verified)**:
   - `InvFileExplorer.tsx`에서 실제 커널 체크아웃 바이트(`WorkspaceEditView`) 로드 및 WebCrypto SHA-256 계산 대조.
   - `verified` (일치) | `mismatch` (불일치/변조 경고) | `unverified` (미검증)의 엄격한 3상태 분기 집행 (미검증이나 불일치를 합격으로 승격 금지).
6. **캐시 은폐 및 실패 은폐 차단 (Never Mask Fresh Failures)**:
   - `ClusterOverview.tsx` 노드 동기화 실패 시 정상 0대 빈 상태 둔갑 차단 (`cluster-overview-fetch-error`, `role="alert"` 에러 뷰 및 재시도 버튼).
   - `RunList.tsx` Run 동기화 실패 시 정상 0건 둔갑 차단 (`run-fetch-error-state`, `role="alert"` 에러 뷰).
   - `ApprovalCenter.tsx` 안건 동기화 실패 시 정상 0건 둔갑 차단 (`approval-fetch-error-state`, `role="alert"`).
   - 폴링 실패 시 기존 캐시가 있으면 최신인 척 침묵하지 않고 `stale-warning` 배너 표출.
7. **시간 신선도 지표화 및 진실 시각 실배선 (Freshness & Truth Time)**:
   - 백엔드 9/9 신선도 필드 실배선 (`RunResultView.stateUpdatedAt`, `ShardObservation.stateAsOf`, `RunArtifactList.completedAt`, `RunLogView.completedAt`, `NodeResponse.lastHeartbeatAt`, `ReplicaObservationResponse.observedAt` 등).
   - 출처별 고유 라벨 부여: `실행 상태 갱신`, `샤드 상태 기준`, `실행 완료 시각`.
   - 오독 방지 부인 고지 결속: `stateAsOf`에 "단일 공통 스냅샷이나 조회 시각이 아닙니다", `completedAt`에 "로그 캡처나 파일 다운로드 시각이 아닙니다" 명시.
8. **허위 미구현(Class 3) 전수 소거 및 실배선 (Honest Capability & Unimplemented Cleanup)**:
   - Claude 백엔드 대조 감사 커밋(`52a3eea4`) 수용: 백엔드에 실재하는 엔드포인트 전수 확인.
   - `RunDetail.tsx` Tab 3 Fallback 아티팩트 다운로드를 실제 커널 엔드포인트(`getArtifactDownloadUrl`)로 실배선, `[모의 고지]` 및 `다운로드 (API 미노출)` 허위 라벨 완전 소거 ➔ `📥 다운로드` 통일.
   - `MonacoWorkspaceEditor.tsx` 저장 API 실재(`saveWorkspaceEditView`)를 반영하여 `(백엔드 저장 API 미노출)` ➔ `(체크아웃 컨텍스트 미연결)` 정직화.
   - `ResourceExplorer.tsx` 논리 점유율의 `미제공 (API 미노출)`은 백엔드에 HTTP 읽기 경로 부재 상태를 정직하게 반영하고 있음을 재확인.
9. **브라우저 alert() 18개소 전소 (Zero Alert Invariant)**:
   - 프론트엔드 전역(`apps/web/src`)의 브라우저 블로킹 다이얼로그 `alert()` 잔여 18개소 전면 소거.
   - WAI-ARIA `role="alert"`(오류) 및 `role="status"`(성공/안내) 인라인 배너로 전환하여 스크린 리더 전달 및 단위 테스트 단언 가능화.
10. **웹 접근성 상태 역할 분리 및 비색상 단서 (Accessibility / WCAG 2.1 AA)**:
    - 스크린 리더 상태 역할 엄격 분리 (`role="alert"` / `aria-live="assertive"` vs `role="status"` / `aria-live="polite"`).
    - 적록 색각 이상자를 위한 비색상 텍스트 라벨 병행 제공 (`[저하]`/`[정상]`, `[VERIFIED]`, `[TAMPERED]`).
    - 조건부 차단된 조작 버튼에 `aria-disabled="true"`, `aria-describedby`, `title` 결속.
