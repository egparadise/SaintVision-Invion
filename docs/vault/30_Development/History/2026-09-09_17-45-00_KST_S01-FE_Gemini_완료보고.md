## 1. 완료 범위 및 AC-01 합격 증거

S01-FE의 승인 범위인 "사용자 여정·디자인 토큰·화면 상태 명세"를 완결하고, 이를 실제 동작하는 프로덕션 프론트엔드 코드베이스(`apps/web`)로 부트스트랩했습니다.

1. **정본 설계 명세서 수립**:
   - [[Gemini Frontend 상세 아키텍처 및 화면 명세]] (SPEC-FRONTEND-001) 확립.
   - 라이트/다크 디자인 토큰, 13개 화면 상세 테이블, 5대 공통 화면 상태(Loading, Empty, Error, Forbidden, Partial Failure) 명세 완결.
2. **프로덕션 SPA (`apps/web`) 구현 완결**:
   - **디자인 시스템 & 토큰**: `src/index.css`, `Button`, `RiskBadge`(L0~L3 이중 코딩), `Skeleton`, `EmptyState`, `ErrorState`(RFC 9457 + W3C traceId).
   - **W3C API 클라이언트**: `client.ts`에 32자 traceId 자동 주입 및 RFC 9457 ProblemDetails 파서 탑재.
   - **실시간 통신 계층**: `sse-client.ts`(1,000개 링버퍼 중복 제거, 지수 백오프) 및 `ws-terminal.ts`(30초 1회용 티켓 인증, SIGWINCH).
   - **핵심 화면 7개 모듈 연결**:
     1. `Login.tsx`: OIDC Code + PKCE 인증 플로우.
     2. `ClusterOverview.tsx`: 5개 분산 Node 클러스터 자원 게이지(CPU/RAM/GPU/Storage).
     3. `NodeList.tsx` & `NodeDetail.tsx`: 5대 노드 인벤토리 및 상세 Capability/Lease 뷰.
     4. `RunList.tsx` & `RunDetail.tsx`: 11개 상태 타임라인, SSE 실시간 로그, Artifacts, 자원 Explain 뷰.
     5. `ApprovalDetail.tsx`: Unified Diff 미로드 차단, Nonce, 타이머, Two-Person Rule 자가 승인 방지.
     6. `EvidenceViewer.tsx`: 불변 증거 JSON 뷰어 및 무결성 검증 뱃지.
     7. `WebTerminal.tsx`: 웹 터미널 및 스크린리더용 접근성 텍스트 로그 대체 뷰.
   - **배포 및 검증**: `nginx.conf`(HTTP/2, SSE 버퍼링 해제), `Dockerfile`(멀티스테이지 경량 이미지), `approval.test.ts`(단위 테스트).
