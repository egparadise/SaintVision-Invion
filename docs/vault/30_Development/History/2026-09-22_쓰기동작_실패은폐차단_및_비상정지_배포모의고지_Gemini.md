## 2. 변경 상세

### A. `ResourceExplorer.tsx` (디스커버리 & 풀 관리 실패 은폐 차단 및 모달 규격화)
1. **상단 메시지 배너 표준화 (`role="alert"` / `role="status"`)**:
   - `storageMessage`: 성공 시 `role="status"`, 실패(❌) 시 `role="alert"` 명시.
   - `poolMessage`: 성공 시 `role="status"`, 실패(❌) 시 `role="alert"` 명시.
   - `livenessMessage`: 성공 시 `role="status"`, 실패(❌) 시 `role="alert"` 명시.
   - `discoveryMessage`: 성공 시 `role="status"`, 실패(❌ 또는 ⚠️) 시 `role="alert"` 명시.
2. **디스커버리 탭 인라인 피드백 배너 및 토큰 모달 보강**:

   - `admissionResult` 토큰 발급 모달에 `data-testid="admission-result-modal"` 및 `role="status"` 부여.
   - 승인 버튼에 `data-testid="admit-candidate-btn"`, 거부 버튼에 `data-testid="decline-candidate-btn"` 부여.
3. **풀 관리 탭 인라인 피드백 배너 보강**:

### B. `AdminSecurityConsole.tsx` (가짜 식별자 합성 소거 & Kill Switch 모의 정직화)
1. **가짜 actor 합성 원천 차단**:
   - `handleTestMount`: `actor || 'usr_security_auditor'` 제거. `!actor` 시 `🛑 ACCESS DENIED: 인증된 관리자 세션 식별자(actor)가 없어 마운트 경로 검증을 수행할 수 없습니다.` 차단 메시지 표출.
   - `handleTestBypass`: `actor || 'usr_bypass_tester'` 제거. `!actor` 시 `🛑 BYPASS BLOCKED: 인증된 관리자 세션 식별자(actor)가 없어 승인 우회 검증을 수행할 수 없습니다.` 차단 메시지 표출.
   - 테스트용 testid 부여: `mount-test-result`, `test-bypass-btn`, `bypass-test-result`.
2. **긴급 Kill Switch 모의 시뮬레이션 투명 고지**:
   - 헤더 토글 버튼: `!actor` 시 `disabled={!actor}`, `aria-disabled={!actor}` 가드 집행.
   - 상단 활성 배너: `🚨 [모의 시뮬레이션] EMERGENCY KILL SWITCH ACTIVE — LOCAL SECURITY ENGINE ISOLATION` 및 `(백엔드 제어 평면 비상 정지 API 미노출 상태로 실제 물리 노드에는 전달되지 않는 로컬 모의 동작)` 고지. `data-testid="kill-switch-active-banner"`, `role="alert"`.
   - 확인 모달: `data-testid="kill-switch-mock-notice"`, `role="status"` 고지 추가:
     `⚠️ [모의 시뮬레이션 고지]: 백엔드 제어 평면 비상 정지 API가 현재 미노출 상태입니다. 본 기능은 프론트엔드 보안 엔진의 로컬 에뮬레이션 상태를 토글하며, 실제 클러스터 물리 노드 작업이나 외부 네트워크를 중단시키지 않습니다.`
