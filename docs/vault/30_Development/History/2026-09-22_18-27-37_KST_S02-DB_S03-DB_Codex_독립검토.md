# S02-DB·S03-DB review 진입 독립 검토

## 판정

Claude의 [[2026-09-22_18-25-00_KST_S02-DB_S03-DB_검토인계패키지_Claude]]를 AC-02·AC-03, TaskCard의 scope·evidence_required, 고정 SHA 시험과 hosted CI에 대조했다. 두 카드는 **`review` 진입을 수용**한다. 이는 구현·증거 묶음이 독립 검토 가능한 상태라는 뜻이며 `done` 판정이 아니다.

- S02-DB: 실제 API→PostgreSQL 경로, 토큰 재사용 거부, tenant/project 격리, 거부 기록, Node/Capability/Snapshot 계약과 브라우저 여정이 검토 입력으로 갖춰졌다.
- S03-DB: Run/Evidence/Workspace DB 불변식, EvidenceEnvelope 앵커 무게와 lease 회수 증거가 검토 입력으로 갖춰졌다. `금지 경로·명령 차단`의 실제 Linux 컨테이너 증거는 DB 단독 증거가 아니며 hosted Core/Node runtime 인수 범위로 남는다.
- 최신 확인: Core Build [35706465645](https://github.com/egparadise/SaintVision-Invion/actions/runs/35706465645)는 SHA `3d1892c0`에서 LAN installer, 전체 core pytest, Docker hygiene, control-plane build, Go, TypeScript까지 모두 success다.

## 완료로 올리지 않는 경계

- S02-DB: 실 IdP, 물리 Node mTLS/heartbeat, browser acceptance의 남은 red, 선행 S01-BE/S01-ST가 미완료다.
- S03-DB: 실 컨테이너 출력 바이트·금지 명령 인수, S03-ST 및 S02 선행 카드가 미완료다.
- 따라서 두 카드의 `review`는 수용하지만 `done` 전환과 전체 AC 충족 주장은 금지한다. 미충족 표를 삭제하거나 skip/not_run을 통과로 세지 않는다.
