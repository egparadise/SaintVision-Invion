# 진척률 재채점

## 산식

기존 산식을 유지했다. 최초 범위의 48개 task를 동일 가중치로 두고 task마다 0/25/50/75/100점을 부여한다. 25점은 계약·뼈대·예시, 50점은 부분 구현 또는 주요 연결 누락, 75점은 상당한 구현과 로컬/고정 SHA 검증, 100점은 전체 범위·선행조건·CI·독립 검토·필수 운영 인수를 모두 충족한 경우다. 따라서 분모는 계속 `48 × 100 = 4,800`이다. 시험 건수나 병합 커밋 수를 점수로 직접 더하지 않았다.

## 세 기준의 현재 수치

| 기준 | 현재 수치 | 분모 | 해석 |
|---|---:|---:|---|
| 로컬 구현·검증 성숙도 | **2,800 / 4,800 = 58.33%** | 48 task × 100 | 기존 채택 기준 2,775점에서 S11-DB만 50→75로 올렸다. 물리 PITR 리허설과 음성 선행조건 게이트가 고정 SHA로 확인됐기 때문이다. 운영 PITR 적용·CI·독립 검토가 남아 100점으로 올리지 않았다. |
| 독립 검토 | **12 / 12 감사 ID 독립 확인**; 전체 formal reviewer gate는 **0 / 48** | 감사 ID 12개 / 공식 task 48개 | VB-AUDIT-01/02, VB-MJS-03~05, VB-AGG-01/02, VB-FIX-01/02, VB-LAUNCH-01 및 관련 후속 ID는 사용자·타 Agent의 독립 확인 기록이 있다. 이것을 48개 task 완료율로 환산하지 않는다. CI와 전체 카드별 reviewer 승인 증거가 없으므로 formal 0/48은 유지한다. |
| 운영 인수 | **0 / 5** | VF 운영 인수 카드 5개 | 로컬 Docker/PG, fixture·합성 앱, 이미지 lane 일부 결과는 실제 5대·원격 profile/mTLS·운영 identity·실제 UI/장비 인수를 대체하지 않는다. AC-12 운영 PITR 적용도 미완료다. |

## 오늘 반영한 범위와 점수 반영 여부

- CX-01 정본 착지, 원격 모델 권한 결속, registry 재검사, frozen registry 결속: 관련 구현과 로컬/고정 SHA 증거를 확인했지만 기존 카드가 이미 50/75 단계였거나 전체 운영 게이트가 남아 추가 점수를 중복 부여하지 않았다.
- 검증 경계 감사 12개 ID, route 계약 정렬, fixture·launcher 수정: 결함 수정과 회귀 시험은 확인했지만 감사 ID와 시험 수를 48 task 점수로 직접 환산하지 않았다.
- 물리 PITR 리허설: 논리 복원이 아닌 `pg_basebackup`/WAL/`recovery_target_time` 경로와 양성·음성 선행조건을 확인했으므로 S11-DB만 50→75로 갱신했다. off-host 운영 저장소, archive 설정 적용, RPO/RTO 운영 인수는 남아 있다.
- 최종 기본 회귀는 `1264 passed / 489 skipped / 2 deselected / 0 failed`(tests/integration 제외, 기본 `not docker_host`, DSN 없음, 69초)로 기록한다. 이 수치 자체를 완료율로 환산하지 않았다.

## 이전 수치와의 변화

기존 `2,775 / 4,800 = 57.81%`에서 `2,800 / 4,800 = 58.33%`로 **25점(0.52%p)** 올랐다. 상승 원인은 오늘 확인된 물리 PITR 리허설의 실패 가능한 양성·음성 게이트 하나뿐이며, 시험 수 증가·커밋 착지·감사 ID 개수는 중복 계상하지 않았다.

## 정식 완료와 운영 조건

`formal 0/48`은 registry의 48개 공식 task가 전체 범위·CI·독립 검토·필수 운영 인수까지 완료 등록되지 않았다는 뜻이며 구현 0%라는 뜻이 아니다. `VF 운영 인수 0/5`는 별도의 실제 운영 인수 카드 5개 분모다. 둘은 4,800점 산식의 분모와도 다르다.

외부 대기 조건은 GitHub Actions 결제 한도, `gh` 인증, 호스트 메모리·OneDrive 핸들 안정화, 원격 실장비 profile/mTLS 설치, AC-12 운영 PITR 적용이다. 재개 시 해당 조건을 충족한 고정 SHA에서 독립 검토와 운영 증거를 다시 확인한다.
