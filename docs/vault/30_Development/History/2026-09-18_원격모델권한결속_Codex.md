# 원격 모델 권한 snapshot과 frozen workload 결속

시작 2026-09-18T12:33:44+09:00, base5e4d6ae, branch agent/codex/model-registry-binding, VF-CX-02/03 owner Codex/reviewer Claude 대기. 공통/개인 진행판, agent-delivery1.1.0/core-reliability1.0.0 적용. 승인된 연속 진행, image lane 추가실행 중단 유지.

범위: 운영자 명시 remote reader를 ModelRuntimeStore에 연결, 읽기 전후 Node/channel/Location/권한을 capture/비교. 원격 channel provenance를 snapshot 및 불변 DB locations 기록에 함께 결속하고 dispatch/claim 시 재검사. registry lifecycle/정책 결속 전체를 완료했다고 표시하지 않는다. 로컬 모델의 기존 동작과 원격 모델의 검사를 생략하는 fallback을 구분한다.

현재 INV_TEST_ADMIN_DSN 없음 확인(값 출력 없음). 로컬 DB 의존 시험은 skip으로 보존하고 fake-DB orchestration과 loopback mTLS 시험을 분리한다. 실PG의 RLS/잠금/동시성 보증을 mock으로 대체했다고 주장하지 않는다.

## 구현 결과

- ModelRuntimeStore에 명시 ConfiguredRemoteModelReader 연결. 기존 _capture가 tenant/project/사용자/Node/Location/상태를 검사하고 capture_channels가 동일 epoch의 현재 enabled·미만료 channel을 SHARE잠금으로 읽는다. 잠금 종료 후 mTLS 읽기, 두 번째 transaction에서 전체 capture 값이 동일한지 검사한 후에만 frozen row를 저장한다. 실패 시 local fallback/재시도 없음.
- 모든 원격 Location 기록에 ChannelProof를 함께 저장한다. 기존 locations JSON array 범위이며 migration/DDL 변경 없다. 불변 runtime row의 locations와 snapshot `model/source.json`의 sourceHash를 비교한다. sourceHash는 채널/위치 정본 전체의 canonical SHA256이며 endpoint/relative_path 원문은 실행파일에 노출하지 않는다.
- source.json 포함 전체 snapshot의 inputSha256가 ModelExecutionRef→WorkloadSpec→기존 action_digest/서명된 계획에 결속된다. 채널정보 일부/전체삭제, 위치변조, local 형식으로 downgrade하면 거부한다. sourceMode를 원격 idempotency payload에 넣어 같은key의 로컬결과를 원격검증으로 재해석하지 못하게 한다.
- 승인 요청 시 frozen source hash와 현재 business permission/channel을 검사한다. delivery/ToolGateway claim에서는 기존 Node/resource lock 후 현재 Node/Location/권한·channel·fence를 재검사한다. prepare replay는 현재 linked business권한도 재확인하되 과거응답을 새 실행permit으로 해석하지 않는다.
- remote/local 선택은 trusted worker 생성자 설정이며 HTTP/caller verified 플래그를 추가하지 않았다. RegistryBindingPolicy/registry lifecycle을 WorkloadSpec 전체 실행권한에 연결하는 단계는 **아직 미구현**이다. 원격 channel 권한 구현을 registry 실행인가 완료로 올리지 않는다.
