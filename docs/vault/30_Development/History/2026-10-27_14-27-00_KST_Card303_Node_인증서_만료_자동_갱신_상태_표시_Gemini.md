# Card 303 Resource Explorer 노드 인증서 만료 및 자동 갱신 상태 표시

## 1. 작업 배경 및 목표
- **배경**: LAN 파일럿 r3 환경에서 2026-10-23 인증서 만료로 인해 클러스터 통신이 단절되었으나, 운영 화면에서는 구체적인 사유 없이 'untrusted' 상태만 단순 노출되어 사전 인지 및 대응이 어려웠습니다. 현재 가동 중인 r4 환경(두 노드 온라인)은 2026-11-02 12:32:25 KST에 인증서가 만료되며, 2026-10-31 12:32:25 KST부터 자동 갱신 윈도우가 개시됩니다. 운영자가 클러스터 인증서 만료 및 갱신 상태를 UI에서 직관적이고 정확하게 확인할 수 있어야 합니다.
- **목표**:
  1. Claude Card 302 데이터 계약(`nodes[i].certificateNotAfter`, `trust`)을 수용하는 프런트엔드 타입 체계 및 관측 매퍼 확립.
  2. `ResourceExplorer` 상단 배너 및 툴바 상태 배지, 개별 노드 행(Overview 탭) 및 상세(Nodes 탭)에 명시적 `Asia/Seoul` (KST) 시각 표시.
  3. 무결성 규칙 준수: '미확인 값은 꾸미지 않음' 원칙에 따라 잘못되거나 누락된 필드는 `undefined` 또는 '미확인'으로 fail-closed 처리.
  4. ACC-09 디자인 토큰 규격 준수: 리터럴 0건(색상 코드 하드코딩 배제), 시맨틱 상태 토큰 및 명도 대비 불변식(텍스트 >= 4.5:1, 테두리 >= 3.0:1) 100% 충족.

## 2. 데이터 계약 및 구현 내역

### 2.1 데이터 계약 구조 (Card 302 연계)
- 노드 항목: `nodes[i].certificateNotAfter: string | null` (ISO-8601 UTC string 또는 null)
- 클러스터 신뢰 요약:
  ```ts
  export type ClusterTrustState = 'ok' | 'renewal-window' | 'expired' | 'unknown';

  export interface ClusterTrustSummary {
    earliestCertificateNotAfter: string | null;
    renewalWindowStartsAt: string | null;
    secondsUntilEarliestExpiry: number | null;
    state: ClusterTrustState;
  }
  ```

### 2.2 구현 세부 사항
1. **계약 타입 (`apps/web/src/contracts/types.ts`)**:
   - `NodeItem` 인터페이스에 `certificateNotAfter?: string | null;` 추가.
   - `ClusterTrustState`, `ClusterTrustSummary` 인터페이스 정의.
2. **관측 매퍼 (`apps/web/src/shared/api/nodeObservation.ts`)**:
   - `observedNode` 함수에서 `certificateNotAfter` 및 `certificate_not_after`를 검증하여 유효한 ISO 날짜 문자열은 그대로 통과, `null`은 명시적 `null`로 보존, 날짜 형식이 아니거나 미확인된 값은 `undefined`로 매핑하여 임의의 값을 날조하지 않도록 방어.
3. **자원 탐색기 컴포넌트 (`apps/web/src/features/desktop/ResourceExplorer.tsx`)**:
   - `ResourceExplorerProps`에 `trust?: ClusterTrustSummary | null;` 지원.
   - `formatKstDateTime(isoString)`: `Intl.DateTimeFormat`의 `timeZone: 'Asia/Seoul'`을 명시적으로 사용하여 브라우저 로컬 타임존 편차를 원천 차단하고 `YYYY-MM-DD HH:mm KST` 형식으로 한국어 시각 표기. 유효하지 않은 입력은 '미확인'으로 fail-closed.
   - `getTrustBannerInfo(trust)`:
     - `renewal-window`: `자동 갱신 창 — 만료까지 N일 N시간` 상단 배너 표시 (남은 시간 초 단위 또는 만료 시각으로부터 일/시간 계산, 음수는 0일 0시간으로 안전 클램프).
     - `expired`: `인증서 만료 — 노드 연결 끊김` 상단 배너 표시 (`role="alert"`).
     - `unknown` 및 필드 부재: 상단 배너 미표시.
     - `ok`: 배너 없이 헤더 툴바에 `● 인증서 정상` 배지만 표시 ("ok=배지만").
   - 상단 툴바 상태 배지: `trust.state !== 'unknown'` 시 상태에 따라 `● 인증서 정상` (`var(--color-status-online)`), `● 자동 갱신 창` (`var(--color-status-degraded)`), `● 인증서 만료` (`var(--color-status-offline)`) 배지 렌더링.
   - 노드 행 (Overview 탭): 각 노드 카드 하단에 `인증서 만료 (KST): {formatKstDateTime(node.certificateNotAfter)}` 표시.
   - 노드 상세 (Nodes 탭): 노드 선택기 우측 및 상세 역량 그리드에 `인증서 만료 (KST): ...` 표시.

## 3. 검증 결과 및 증거

### 3.1 단위 시험 (`apps/web/tests/node-cert-trust-expiry.test.tsx`)
- 총 27개 단위 시험 전수 통과:
