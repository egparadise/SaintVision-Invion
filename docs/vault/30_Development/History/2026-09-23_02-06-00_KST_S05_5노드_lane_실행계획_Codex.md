# S05-DB 5노드 lane 실행 계획

## 범위와 결론

[[Codex 5노드 랩 opt-in lane 정의]]를 v1.1로 갱신해 카드 14의 S05 benchmark와 F-S05-03을 물리 5노드 실행 입력으로 연결했다. 이번 카드는 **docs-only 계획**이며 workflow, 제품 코드, 계약, registry, ontology를 바꾸거나 물리 부하를 실행하지 않았다.

5노드 lane은 아직 실행 가능 상태가 아니다. 현재 `tools/placement_benchmark.py`는 실 PostgreSQL을 사용하지만 합성 node/resource row를 만들기 때문에 랩 runner에서 실행해도 물리 증거가 아니다. inventory-bound adapter 또는 동일 schema의 `run_s05_five_node_benchmark.py`는 제안·미구현이며, 카드 18의 F-S05-03 구현 검토와 코디네이터 후속 결정이 선행돼야 한다. 50동시는 그 결정 SHA와 20동시 canary 통과 없이는 시작하지 않는다.

## 추가한 실행 계약

- 별도 self-hosted Linux workflow, environment `five-node-lab`, concurrency group `saintvision-five-node-lab`, `cancel-in-progress: false`, 동시 실행 1개를 고정했다. 일반 Core push가 물리 측정을 취소하지 않는다.
- S05 입력을 `legacy,short-commit`, wave `20,50`, mode별 3회, 90초 process timeout, 기본 off `placementShortCommit`, 카드 18 이후 결정 SHA로 고정했다. mode 또는 20동시를 생략한 50 단독 실행은 금지한다.
- 동일 code/inventory/image/policy/request에서 mode만 바꾸고 repetition 순서를 교차한다. 각 repetition 뒤 stop receipt·active lease 0·실 heartbeat freshness를 복원한다.
- 20동시는 invariant canary, 50동시는 AC-05 wave다. candidate의 lock-hold P95 감소와 내부+외부 `55P03/57014` 합계 감소를 모두 요구하며 성공 수만으로 통과시키지 않는다.
- JSON/JUnit 외에 manifest, canonical decision digest, schema 1.3 `lockHold`·`limitRowWait`, retry/SQLSTATE 분포, comparison, redaction evidence를 필수 artifact로 정했다.
- 카드 14 개발 PC 수치(hold P95 1399.883→122.126ms, 요청 P95 1771.763→1697.737ms, candidate limit-row `55P03` 14/10/11)는 랩 예상값이 아니라 회귀 비교 입력으로만 사용한다.

## 랩 준비 대응표

물리 node 5대, resource 기준선, NTP, CA/control cert, node cert 5개, 네트워크, disposable PostgreSQL, clean checkout와 immutable image digest, 빈 evidence root, GitHub Environment 승인·직렬화의 열 항목을 각각 다음에 연결했다.

1. workflow/input 또는 secret **이름**
2. 실행 전 수집할 redacted preflight evidence
3. 부하를 시작하지 않아야 하는 차단 기준

NTP는 모든 node의 sync state·source·offset·stratum을 남기고 커널 경계 `abs(clock_skew_seconds)≤5`를 초과하면 중단한다. 목표 `≤1s` 미달은 warning과 실제 값을 보존한다. mTLS는 inventory의 expected subject/SAN/fingerprint와 node ID를 1:1 대조하고 revoked/unknown cert 부정 대조를 포함한다. private key·DSN·token 값은 문서와 artifact에 넣지 않는다.
