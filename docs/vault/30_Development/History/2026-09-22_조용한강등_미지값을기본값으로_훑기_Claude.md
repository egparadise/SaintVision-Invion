# 조용한 강등 훑기 — 미지값을 그럴듯한 기본값으로 바꾸는 자리

## 무엇을·왜
오늘 밤 세 번째로 나온 모양: **모르는 것을 모른다고 안 하고 아는 것처럼 바꿔버린다.** (①건너뛰기가 통과처럼 보임 ②헤더 부재가 정상처럼 보임 ③읽은 값이 예상 밖일 때 오류/모름 대신 **그럴듯한 기본값**으로.) 원형은 `observedNode`: 모르는 status가 오면 `'enrolling'`으로 강등하고 텔레메트리 없음·스케줄 불가로, **조용히**. 이 부류가 또 있는가를 매퍼·변환기·파서에서 훑었다. 훑기만·미고침.

**판정 기준(과잉 flag 방지)**: 결함 = **미지/예상밖 값을 그럴듯한 known 값으로 대체해 이상을 숨김**. 결함 아님 = 오류를 낸다(fail-closed) · 모름을 모름으로 표시한다 · allowlist로 실제 값을 보존한다 · 실조건에서 계산한다.

## 프런트 (Gemini 레인) — 3건 + 경미 1
- **A. `shared/api/nodeObservation.ts:24`** (원형, [[2026-09-22_느슨한계약열거_화면죽은분기_부류훑기_Claude]] §A와 동일): `[...6set].includes(raw.status) ? raw.status : 'enrolling'`. 계약이 내는 `active`·`lost`가 6-set에 없어 **정상 노드가 'enrolling'으로 위장**. status는 거짓말, telemetryUnavailable=true만 정직. **고침**: 프런트 어휘 정합(§A 결정 후).
- **B. `shared/api/workspaceEditObservation.ts:99`**: `const wsId = editView.snapshot.workspaceId || 'default-workspace'`. workspaceId가 비면 **'default-workspace'라는 그럴듯한 id로 위장**되어 파일 URI `inv://workspaces/default-workspace/...`에 박힌다 — 어느 작업공간 파일인지 오귀속. 계약 검증(throw)이 workspaceId **비어있지 않음**까지 보장하는지 불확실하면 잠복 강등. **고침 권고**: 비면 오류/빈-표시(기본 id 위장 금지).
- **C. `shared/api/workspaceEditObservation.ts:108`**: `catch { decodedContent = f.dataBase64 }`. base64 디코드 실패 시 **raw base64를 "디코드된 내용"으로** 제시 — 디코드 실패를 성공처럼. **고침 권고**: 실패를 실패로 표시(내용 미표시/오류).
- **D(경미). `shared/api/runArtifactObservation.ts:89`**: `fallbackFileName || path.split('/').pop() || 'artifact.bin'`. 이름 없는 다운로드에 'artifact.bin'. 상태 위장이 아니라 표시용 파일명이라 경미. **다운로드 = Codex 활성 영역**이라 짚기만 하고 미접촉.

## 백엔드 (변환기·파서·자격증명) — 0건
훑은 결과 조용한 강등 **없음**. 오히려 정석 예시:
- `adapters/cli.py:313,317`: 로그인 상태 파싱 실패 → `LoginState.UNKNOWN` + 명시 이유("status output was not JSON"). **모름을 모름으로**(정답, 원형의 반대).
- `credentials/linux_file.py:45,66,89`: `except Exception → raise CredentialDenied()` / `except BaseException → cleanup; raise`. **fail-closed**(기본값 반환 아님, 거부·전파).
- `identity/discovery_credentials.py:43`: `reason_code if reason_code in _REASONS else "grant_rejected"`. 처음엔 강등처럼 보였으나 — 코드가 실제 넘기는 12개 reason 전부 allowlist(13)에 있고 else는 **미발화 안전망**(외부 미지 코드용). 실제 값 **보존**. 결함 아님.
- `services/eval_execution.py`, `services/evaluation.py`: passed/failed·completed/aborted를 **실조건(카운트)에서 계산**. 미지 대체 아님.

## 공통 원리와 인계
- 원리: 원형(nodeObservation)의 위험은 **status를 known 값으로 거짓말**한 것이다. 같은 파일이 telemetryUnavailable=true로 "모름"을 표시하면서도 status만은 위장했다 — 부분 정직이 더 함정. 정석(cli.py UNKNOWN)은 값 자체를 UNKNOWN으로 둔다.
- **훑기만 했고 고치지 않았다.** 프런트 A/B/C는 **Gemini 인계**. D는 Codex 다운로드 영역이라 짚기만. 백엔드는 결함 없음.
- Codex 충돌 회피: runArtifactObservation(다운로드)·저장소 파일은 미접촉.
