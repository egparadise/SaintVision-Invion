# 화면 정직성 스캐너 7대 규칙 확장 및 양방향 실측 사살

## 1. 배경 및 목적
- 화면 결함 치유 트랙을 거치며 기존 5대 규칙(자리표시자 식별자, 0-Call 가드, 조기 성공 표시, 티켓 로깅 차단, 3상태 무결성) 외에 **시간 신선도(Time Freshness)**와 **허위 미구현(False Unimplemented)**이라는 신규 결함 부류가 도출됨.
- 사용자의 지시:
  - 스캐너에 신규 부류(규칙 6: 시간 신선도 합성 차단 및 한정 고지, 규칙 7: 허위 미구현 모순 차단)를 규칙으로 추가.
  - 전부 규칙으로 만들 수 없는 영역(시간의 실제 참값, 백엔드 라우트 실재 여부, 수명주기 조건 미충족의 미구현 오판)을 스캐너 한계(7~9)로 명확히 분리하여 거버넌스에 명시.
  - 새 규칙 각각에 대해 프로덕션 코드에 고의 위반(돌연변이)을 주입해 exit 1로 탐지되는지 실측 사살(KILLED)하고 원복하는 양방향 검증 수행.

## 2. 작업 내용

### 1) 프로덕션 잔여 합성 타임스탬프 제거 (`DeveloperStudio.tsx`)
- `DeveloperStudio.tsx` L483, L541에 남아있던 `exportedAt: res.completedAt || new Date().toISOString()` 가짜 현재 시각 합성을 완전 소거하고 `exportedAt: res.completedAt || null`로 정직화.

### 2) `tools/check_frontend_integrity.py` 7대 규칙으로 확장
- **규칙 6: Synthetic Timestamp Fallback & Qualification Invariant (신선도 지어내기 차단 및 한정 고지)**:
  - 백엔드 타임스탬프 변수(`completedAt`, `stateUpdatedAt`, `stateAsOf`, `lastHeartbeatAt`, `observedAt`, `committedAt`, `exportedAt`)에 대해 `|| new Date().toISOString()` 또는 `|| Date.now()`로 클라이언트 현재 시각을 합성하여 타임스탬프를 위조하는 패턴을 탐지(`SYNTHETIC_TIMESTAMP_FALLBACK_REGEX`).
  - `RunDetail.tsx` 등 핵심 뷰에서 `stateAsOf` 렌더링 시 "단일 공통 스냅샷이나 조회 시각이 아닙니다", `completedAt` 렌더링 시 "로그 캡처나 다운로드 시각이 아닙니다"라는 부인 고지(Disclaimer) 결속 여부 검사.
- **규칙 7: Honest Capability & Unimplemented Consistency Invariant (허위 미구현 모순 차단)**:
  - 오늘 적발된 거짓 미구현 라벨(`서버 아티팩트 파일 스트림 다운로드 API 미노출 상태`, `다운로드 (API 미노출)`, `인메모리 워크스페이스 에디터 (백엔드 저장 API 미노출)`, `로컬 인메모리 버퍼에 저장합니다 (백엔드 저장 API 미노출)`)을 금지 목록(`FORBIDDEN_FALSE_UNEXPOSED_NOTICES`)으로 영구 차단.
  - 동일 파일 내에서 API 엔드포인트/헬퍼(`getArtifactDownloadUrl`, `saveWorkspaceEditView`)를 import/호출하면서 화면에 "API 미노출"이나 "미구현"이라고 주장하는 모순 패턴 탐지(`WIRING_CONTRADICTION_PATTERNS`).

### 3) 스캐너의 9대 구조적 한계와 사람 판단 영역 확립
- 거버넌스 문서(`docs/vault/40_Governance/화면_개발_정직성_지침_및_사례집.md`) 및 스캐너 독스트링에 3대 한계 추가:
  - **(7) 타임스탬프의 시간적 진실성과 클록 스큐**: 스캐너는 라벨과 디스클레이머의 존재를 볼 뿐, 실제 DB 트랜잭션 기록 시각인지, 노드 간 클록 스큐(5초)가 있는지, 복제본 관측 시각이 재검증 필요를 담고 있는지는 알 수 없음 (Codex PG16 연동 시험 몫).
  - **(8) 백엔드 라우트 실재성 vs 화면의 미구현 표기**: 화면에 "미제공"이라 적힌 것이 실제 엔드포인트 부재인지 프론트엔드의 오판인지는 백엔드 라우트 테이블 대조 필요 (Claude 백엔드 대조 감사 레인).
  - **(9) 수명주기 조건 미충족 / 대역외 안내의 미구현 둔갑**: 실행 중(running) 미가용이나 물리 노드 CLI 실행 안내를 프론트엔드가 기능 부재로 오판하는 것은 도메인 지식이 필요하며 정적 문맥만으로는 판정 불가.
