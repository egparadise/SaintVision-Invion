## 3. 러너 결함 (F5, 재현으로 확인)

1. **예외 경로 `UnboundLocalError`**: 507행 이전(서비스 기동 실패 등)에서 예외가 나면 1354행 `stopped_due_to_memory` 미정의로 handler가 다시 죽어 **evidence 미기록·traceback 종료**(1회차 재현 로그). `stopped_due_to_memory = False`를 try 앞으로.
2. **Vite 자식 누수**: cleanup은 `npm.cmd` 래퍼만 `terminate` → node/vite 자식이 3005에 계속 bind(2회차 종료 후 PID 32836 확인, 직접 kill). 다음 실행은 `start_frontend`의 "Port already active" 분기로 **다른 체크아웃의 stale Vite를 조용히 재사용**할 수 있어 재현성 훼손. 프로세스 트리 종료(`taskkill /T` 또는 job object) + 포트 소유 확인 필요.
3. **메모리 가드 비활성**: `check_mem`은 `psutil` 부재 시 `(True, 2.0)` 반환 → 저장소 `.venv`(psutil 없음)에서는 작업판이 말한 1.0GB 가드가 **작동하지 않고 "여유 2.00GB"를 출력**(내 로그). 의존성 명시 또는 부재 시 UNMEASURED.
4. **FAIL 분포 불일치**: 예외 evidence의 `summary.failed = max(1, …)`이지만 `scenarios`에 실패 시나리오 record가 없음(내 evidence: passed 1·failed 1인데 record는 exp-00 하나). 실패 시나리오 id·사유를 FAIL record로 남길 것.
5. **exp-01 클릭 차단**: `승인 센터` 버튼이 `<span>` overlay(div subtree)에 가려져 30초 timeout — 러너 상호작용이 현재 화면 상태에 취약(overlay 닫기/`force` 대신 원인 확인 필요).
