## 2. 주요 구현 내역 (`apps/web`)

1. **자연어 요청 및 프롬프트 보안 검증 매니저 (`agentEngine.ts`)**:
   - 사전 비행 누출 스캐너 (`scanPromptForLeaks`): 시스템 프롬프트 덤프 시도, API 키(`sk-...`), SSH 개인키, `/etc/shadow` 추출 시도를 정규식 기반으로 사전 차단하여 누출 건수 `0` 엄격 보증 (`AC-09`).
   - 토큰 및 비용 예측기 (`estimateTokensAndCost`): 사용자 프롬프트와 참조 Context 파일 수에 기반한 예상 토큰 및 원화 비용 산출.
   - 테넌트 예산 쿼터 가드: 잔여 테넌트 예산(초기 650,000 KRW) 초과 요청 시 `BUDGET_EXCEEDED` 사전 차단.
   - Bounded Repair Loop 관리기 (`advanceRepairLoop`): 무한 루프에 의한 비용 폭발을 방지하기 위해 단일 요청당 최대 3회로 보정 루프 엄격 제한 (`maxRepairLoops: 3`), 4회째 초과 시도시 `BOUNDED_LOOP_EXCEEDED` 발생 및 자동 반려 처리.
   - Golden Eval 벤치마크 엔진 (`evaluateGoldenSuite`): 100건 프롬프트 유효율 99%, 30건 코딩 과제 성공률 80%(24건 통과), 누출 0건 실측 검증.

2. **자연어 Run 요청 및 Diff 검토 화면 (`NaturalLanguageRunView.tsx`)**:

     - 테넌트 잔여 예산: 실시간 잔액 표시
   - 자연어 목표 입력기 및 빠른 예시 프리셋(정상 코딩 과제, 프롬프트 누출 시험).
   - 참조 Context 파일 선택 칩 목록 및 실시간 토큰/비용 미리보기 박스.
   - 제안된 코드 Diff 검토 드로어:
     - Agent가 도출한 코드 Diff 시각화.
     - Bounded Repair 카운터 (`Loop 1/3`).
