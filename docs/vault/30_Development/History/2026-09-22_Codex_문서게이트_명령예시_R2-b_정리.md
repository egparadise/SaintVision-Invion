# 문서 게이트 명령 예시의 R2-b 정리

- 작성자: Codex
- 대상: `GOV-GIT-001`, `AGENTS.md`, 개발환경 이전 절차서
- 목적: 문서가 게이트 없이 명령을 나열하거나 파이프/세미콜론으로 실패를 숨기지 않도록 교정

## 수정

- `AGENTS.md` 검증 절에 PowerShell `$LASTEXITCODE`와 Bash `rc=$?` 조건문을 추가했다.
- `docs/vault/40_Governance/Git Build Obsidian 운영 절차.md`의 명령 블록을 exit 조건형으로 바꿨다.
- `개발환경_이전_절차서.md`의 `| tail -1` 두 곳을 제거하고 원래 명령의 exit를 즉시 검사하도록 바꿨다.
- `tail`은 파이프 뒤 명령의 exit를 전달할 수 있어 원래 게이트 실패를 숨길 수 있으므로 사용하지 않는다.

## 실제 실행

- 문서 예시 `python tools/check_docs.py`: exit 0
- 문서 예시 `python tools/check_ontology.py`: 처음에는 `rdflib` 부재로 exit 1; 문서가 지정한 `requirements-docs.txt` 설치 후 exit 0
- ontology 재실행 결과: RDF/SHACL/48 task mapping 검사 PASS
- 의도적 red gate 변형: gate exit 1에서 `throw`로 중단, push marker 미생성 확인
- `git diff --check`, `check_docs.py`, `check_ontology.py`: 모두 exit 0

이 기록 이후 commit/push는 위 exit 조건을 통과한 뒤에만 수행한다.
