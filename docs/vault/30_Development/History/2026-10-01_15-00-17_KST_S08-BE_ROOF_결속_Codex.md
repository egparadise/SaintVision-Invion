# S08-BE Build 경로 ROOF 결속

## 선택 근거와 기준

- PR #269 head `c5bd3db4f1d3430fd893e118dd97bc9ab8736273`에서 strict
  `BuildRequest`·`BuildPlan`·`BuildReceipt` 계약과 exact-head Core run
  `36819320522`가 green이 됐다. Claude r3의 조건 W2도 닫혔으므로 승인된 설계
  `S08-BE ROOF·BuildKit·단일 GPU 구현 설계` v1.1.0(`ecb43d4d`) 순서에서 다음 내부
  경계인 ROOF 결속을 선택했다.
- 이 branch는 #269 위 stack이다. 새 공개 route, BuildKit daemon/socket, registry push,
  GPU provider, migration은 포함하지 않는다.

## 구현

- `services/control-plane/src/inv/build_governance.py`에 외부 build 호출 전
  `authorize_build`와 호출 후 새 transaction에서 반복하는 `revalidate_build`를 추가했다.
  두 경계는 live project request 권한, business mapping, tenant kill switch, 정본
  `PolicyDecision`, policy version·expiry, request/action digest, fresh measured builder
  instance/profile/recovery epoch를 모두 다시 대조한다.
- provider observation freshness는 aware timestamp 기준 15초이며 claimed-only·미래·stale·
  plan drift는 dispatch 권한이 되지 않는다. pre-dispatch binding digest가 final revalidation과
  다르면 `VERIFY-0002`로 닫힌다.
- 내부 `_build_evidence`는 receipt scope/source/plan/policy/trace를 대조하고 결과별 exact audit
  event 집합과 순서, timestamp, output digest, cleanup digest를 검증한다. 성공 외 결과는
  cache retained를 거부하고 lease·builder claim·cgroup 정리가 모두 확인돼야 정본
  `EvidenceEnvelope`를 만든다.
- 공개 completion primitive인 `finalize_build`는 먼저 live revalidation을 호출하므로
  kill switch·권한·policy·provider 검사를 건너뛴 채 Evidence만 만드는 경로가 없다.
- 실패 terminal audit을 모호하게 남기지 않도록 `BuildAuditEvent.event`에
  `build_failed`를 추가하고 Python·TypeScript·Node schema mirror를 재생성했다.
- `containment.py`의 canonical request hash import는 동작이 같은
  `policy.action_digest` alias로 옮겼다. containment 동작·형식은 바꾸지 않고 ROOF
  경계가 approval/run 모듈을 불필요하게 import하지 않게 했다.

## 되살림 방지 시험

| 제거·완화 변이 | 실패하는 단언 |
|---|---|
| project grant 또는 kill switch 검사 제거 | disabled grant·active kill에서 각각 `AUTH-0030`·`AUTH-0061` |
| policy deny/expiry 검사 제거 | `AUTH-0012` |
| provider freshness 검사 제거 | 16초 stale observation `RES-0003` |
| request/action/policy/provider 결속 하나 제거 | 필드별 8개 drift가 `VERIFY-0002` |
| final transaction 재검증 제거 | authorize 뒤 kill 활성화 시 revalidate 거부 |
| receipt scope/source/trace/audit digest 결속 제거 | 9개 독립 drift 거부 |
| cleanup 확인 또는 cache quarantine 제거 | false cleanup·failed retained cache 거부 |
| 결과별 terminal event·순서·timestamp·digest 결속 제거 | success/failed/cancelled 부정 대조군 거부 |

## 정직성 경계

- 이 결과는 BuildKit **실행 성공**이 아니라 adapter가 우회할 수 없는 ROOF runtime
  primitive와 PG-free 부정 시험이다. daemon, rootless user namespace, seccomp/LSM/cgroup,
  network/secret/cache, 실제 cancel은 여전히 `NOT_OBSERVED`다.
- `EvidenceEnvelope`를 반환하지만 DB에 persist하거나 외부 builder를 호출하지 않는다.
  그 책임은 다음 BuildKit adapter 카드다.
- S08-BE registry 상태·점수와 물리 인수 판정은 변경하지 않는다.
