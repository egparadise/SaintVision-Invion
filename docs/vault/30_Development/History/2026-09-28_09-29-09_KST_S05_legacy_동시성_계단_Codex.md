# S05 Card46 legacy 동시성 계단 hosted lane

## 실행 전 구현

Card42 v1.2의 사전 기준을 코드로 고정했다.

- opt-in workflow: `.github/workflows/s05-legacy-staircase.yml`
- runner: `tools/run_s05_legacy_staircase.py`
- PG-free 회귀: `tests/test_s05_legacy_staircase.py`
- 원본 benchmark report: 일회용 DB 이름을 노출하지 않는 SHA-256 fingerprint 추가

각 wave가 별도 일회용 DB를 쓰고 실행 전후 잔존 0·fingerprint 전부 유일을 검사한다. timeout은 세 wave 최대값, 누적 request P95 all은 세 wave 중앙값으로 판정한다. `2000ms`는 개별 SQL timeout이 아니라 여러 statement를 포함한 요청 전체 경로 기준이다.

로컬에서는 PostgreSQL·부하를 실행하지 않았다. focused PG-free 시험과 YAML/docs 게이트만 실행하며 실제 수치는 PR head를 checkout한 hosted lane에서만 만든다. candidate 실행 0, S05-DB `in_progress`, 승격 없음이다.
