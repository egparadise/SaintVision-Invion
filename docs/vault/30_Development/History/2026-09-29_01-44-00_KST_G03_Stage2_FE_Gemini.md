## 2. 작업 상세 내용

### 1) 계약 스키마 및 가드 계층 (`shared/api/adapterObservation.ts`)
- **Discriminated Union 계약 수용**:
  - `ConformanceStatusUnion` = `ConformanceStatusResponse` (`status === 'NOT_OBSERVED'`) | `ConformanceStatusRecordedResponse` (`status === 'RECORDED'`).
  - `AdapterConformanceUnion` = `AdapterConformanceNotObservedResponse` (`status === 'NOT_OBSERVED'`) | `AdapterConformanceRecordedResponse` (`status === 'RECORDED'`).
- **정본 런타임 가드 구현**:
  - `isConformanceStatusRecordedResponse`: exact keys (`status, scope, contractVersion, adapters, checks, records, latestRecordedAt`), `records` 내 각 항목의 `subject === 'fixture-adapter'`, `provenance === 'in-server'`, `total === passed + failed + skipped`, `outcomes.length === total`, outcome `!(passed && skipped)` 불변식 검증.
  - `isAdapterConformanceNotObservedResponse` 및 `isAdapterConformanceRecordedResponse` 단건 계약 가드 구현.
- **단건 조회 클라이언트**:
  - `fetchAdapterConformance(projectId, adapterName)` 구현 (`GET /v1/projects/{projectId}/adapters/{adapterName}/conformance`).

### 2) UI 컴포넌트 구현 (`ModelLineageView.tsx`)
- **목록 화면 RECORDED 분기 표출**:
  - `NOT_OBSERVED` 시 새 정본 reason (`No conformance run is recorded for this host and these adapters.`) 표출.
  - `RECORDED` 시 `latestRecordedAt`, 어댑터별 실행 기록 테이블(`records`) 표출 (`data-testid="conformance-records-table"`).
  - 허위 "PASS"나 임의의 백분율(100%)을 생성하지 않고 `subject`(`fixture-adapter`), `provenance`(`in-server`), `전체/통과/실패/건너뜀` 카운트를 서버 값 그대로 정직하게 노출.
- **단건 Conformance 상세 조회 및 드릴다운 카드**:
  - 목록 테이블에서 어댑터별 [상세 조회] 버튼 클릭 시 해당 어댑터 단건 조회 연동.
  - 독립된 단건 어댑터 입력폼 및 조회 버튼 (`data-testid="single-conformance-adapter-input"`, `single-conformance-fetch-btn`) 제공.
  - 결과 표출 카드 (`data-testid="single-conformance-result-container"`): `status`, `subject`, `provenance`, 카운트 요약, 개별 검사 항목 체크리스트 표출.
- **엄격한 Fail-Closed 오류 처리**:
  - `404 RES-0004`: "어댑터 없음" 표출, 사용자가 입력한 어댑터 문자열 에코 차단, 재시도 버튼 미노출.
  - `500 SYS-0002`: 서버 host identity 미설정 고정 안내, 재시도 버튼 미노출.
  - `503 SYS-0001`: 리소스 잠금 안내 및 "다시 시도" 버튼 (`data-testid="single-conformance-retry-btn"`) 표출.
  - 계약 불일치 시 fail-closed 오류 배너 표출.
- **상태 격리 (State Isolation)**:
  - 단건 어댑터 입력값 변경 시 단건 결과 컨테이너 즉시 초기화.
  - 프로젝트 ID 입력값 변경 시 목록 결과 및 단건 결과 컨테이너 동시 초기화.
