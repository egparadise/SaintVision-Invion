## 2. 주요 구현 내역

### 2.1. 트랙 1: 프론트엔드 실시간 통신 및 PWA 오프라인 지원
1. **상단 헤더 실시간 Gateway RTT & 연결 상태 배지 ([`Header.tsx`](file:///C:/Project/SaintVision-Invion/apps/web/src/shared/ui/Header.tsx))**:
   - 5초 주기 `/v1/health` 핑을 통한 실시간 왕복 지연시간(RTT ms) 측정.
   - 정상 시 `Gateway: {rtt}ms` (Online), 장애 시 `Gateway: Offline` 적색 배지 시각화.
2. **폐쇄망(Air-Gapped) 전용 PWA Service Worker & 매니페스트**:
   - [`manifest.json`](file:///C:/Project/SaintVision-Invion/apps/web/public/manifest.json): Standalone PWA 메타데이터 및 다크 테마 설정.
   - [`sw.js`](file:///C:/Project/SaintVision-Invion/apps/web/public/sw.js): 정적 에셋 Cache-First, 내비게이션 Network-First 및 오프라인 캐시 폴백 지원.
   - [`main.tsx`](file:///C:/Project/SaintVision-Invion/apps/web/src/main.tsx): 프로덕션 환경 Service Worker 자동 등록.
3. **헤드리스 브라우저 E2E Smoke 자동화 스크립트 ([`run_browser_smoke.mjs`](file:///C:/Project/SaintVision-Invion/tools/run_browser_smoke.mjs))**:
   - Root HTML, #root 마운트, PWA 매니페스트, sw.js, `/v1/health` W3C 헤더, `/v1/nodes` 5대 노드, RFC 9457 404 Problem Details 등 15개 항목 종단간 자동 검증 (15/15 PASS, 100%).

### 2.2. 트랙 3: 엔터프라이즈 Docker 인프라 패키징
1. **TLS 1.3 사내 엔터프라이즈 인증서 자동 생성기 ([`generate_tls_cert.py`](file:///C:/Project/SaintVision-Invion/tools/generate_tls_cert.py))**:
   - `cryptography` 라이브러리를 활용한 2048-bit RSA 및 SAN(saintvision.internal, *.node, localhost, 192.168.1.101~105) 인증서 및 개인키 생성 (`deploy/certs/`).
2. **PostgreSQL RLS 초기화 스크립트 ([`init-db.sql`](file:///C:/Project/SaintVision-Invion/deploy/init-db.sql))**:
   - 비인가 우회 차단용 `NOBYPASSRLS`를 적용한 `inv_app` 롤 자동 생성.
3. **백엔드 컨테이너 정의 ([`Dockerfile.backend`](file:///C:/Project/SaintVision-Invion/deploy/Dockerfile.backend))**:
   - Python 3.11-slim 기반 의존성 설치, Alembic 마이그레이션 및 Control Plane Gateway 구동.
4. **통합 프로덕션 오케스트레이션 ([`docker-compose.prod.yml`](file:///C:/Project/SaintVision-Invion/docker-compose.prod.yml))**:
   - `web` (Nginx TLS 1.3 / Port 8443, 8081)
   - `control-plane` (FastAPI / Port 8080)
   - `postgres` (PostgreSQL 16 / Port 5432)
   - `minio` (S3 호환 로컬 스토리지 / Port 9000, 9001)
5. **원클릭 배포 파이프라인 스크립트 ([`deploy_intranet.ps1`](file:///C:/Project/SaintVision-Invion/tools/deploy_intranet.ps1))**:
   - 5단계(인증서 확인 $\rightarrow$ Vitest 17개 스위트 $\rightarrow$ Vite 빌드 $\rightarrow$ E2E Smoke 15건 $\rightarrow$ 도커 가이드) 자동화 파이프라인 실행.
