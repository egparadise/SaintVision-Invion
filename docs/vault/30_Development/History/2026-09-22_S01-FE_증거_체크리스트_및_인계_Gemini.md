# S01-FE 증거 체크리스트 및 검토 인계

> **⚠ 범위 경계 — 전체 승인 아님.** 본 문서가 다루는 범위는 S01-FE의 고유 승인 범위인 **"사용자 여정·디자인 토큰·화면 상태 명세"** 소프트웨어 구현체 및 설계 정합성에 한정된다.
> **포함되지 않는 것**: 물리 장비 5대 인수, 사내 DNS/TLS 실 인증서 발급, 외부 Keycloak IdP 실제 가동, hosted CI 실행. 본 문서를 S01 전체 완료의 근거로 읽지 않으며, S01-FE 범위 밖의 기능(예: S04 multipart 업로드, S11 분산 스토리지 등)을 억지로 끌어오지 않는다.

- **화면 라우트 계약 검증**: `tests/test_route_coverage.py` **30 passed in 0.82s** (화면 라우트와 백엔드 API 계약 100% 매핑 확인).
- **실제 Google Chrome 153 브라우저 여정 실측**:
  - `RunDetail` 타임라인 마운트 ➔ `🔍 불변 증거 열람` 클릭 ➔ `EvidenceViewer` 전이 ➔ `← 이전으로 돌아가기` 복귀 왕복 내비게이션 실측 (`scratch/real_chrome_rundetail_timeline.png`).

  - `ResourceExplorer` 디스커버리 후보 노드 및 부트스트랩 토큰 발급 모달 실측 (`scratch/real_chrome_discovery_candidates.png`).

### 1.2 디자인 토큰 (Design Tokens)
- **CSS 커스텀 프로퍼티 시스템**: `apps/web/src/index.css` 및 SPEC-FRONTEND-001 §2.1에 Surface, Typography, Brand, Status, Risk(L0~L3), Spacing, Radius 등 30개 시맨틱 토큰 선언.
- **WCAG AA 색각 보정 및 이중 코딩**: 단순 색상 식별을 금지하고 `아이콘 + 텍스트 라벨 + 4.5:1 명도 대비`를 결합 (`RiskBadge.tsx`, `StatusBadge`).
- **실제 Blink 엔진 계산값 실측**: 실제 Google Chrome 153에서 계산된 CSS를 직접 실측하여 `ready` 녹색(`color: rgb(63, 185, 80)`, `backgroundColor: rgba(46, 160, 67, 0.2)`) 렌더링 단언 (`scratch/real_chrome_workspace_ready_green.png`).

### 1.3 화면 상태 명세 (Screen State Specifications)
- **공통 5대 화면 상태**: Loading(스켈레톤), Empty(CTA 액션 포함), Error(RFC 9457 + W3C traceId 복사), Forbidden(403 RBAC 명시), Partial Failure(인라인 격리) 규약화 및 전 컴포넌트 분기 구현.
- **정본 계약 기반 상태 기계 정합**:
  - **Node**: DB CHECK 5대 계약(`enrolling`, `active`, `draining`, `lost`, `retired`) 및 미지(`unknown`) 정직화.
  - **Workspace**: 백엔드 5대 정본 계약(`provisioning`, `ready`, `suspended`, `deleting`, `deleted`)으로 좁히고 프런트 상상 잉여 어휘(`active`, `terminating`, `reclaimed`) 완전 소거.
  - **Evidence**: 4대 상태(`PASS`, `UNVERIFIED`, `RUN_FAILED`, `FAIL`) 분리. 실행 실패(`state === 'failed'`)를 출력 손상(`FAIL`)으로 왜곡하지 않고 `RUN_FAILED`로 정직하게 고지.
  - **Approval**: Diff 필수 로드 가드, One-time Nonce 발급, Two-Person Rule(1차/2차 자가승인 차단), 만료 타이머.
- **프런트엔드 정직성 스캐너 검증**: `python tools/check_frontend_integrity.py` 82개 소스 파일 **0 violations** (All 7 rules satisfied).
