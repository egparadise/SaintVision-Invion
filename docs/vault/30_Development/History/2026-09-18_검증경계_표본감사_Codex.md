# 검증 경계 표본 감사와 실패 가능한 조건

## 작업 계약·범위

사용자 지정 네 패턴(자기 생성 상태 검증, 선행조건 부재의 성공 처리, 단언 전 예외 은폐, 목표에서 파생한 비교값)을 감사했다. base 484c408, branch agent/codex/model-registry-binding, owner Codex, reviewer Claude(미검토), task 검증 경계 표본 감사. agent-delivery1.1.0/core-reliability1.0.0 적용. 시작 공통판1.0.97/Codex1.0.64/상태지도1.1.0 확인.

Python tools51/tests179파일에 rg 검색 및 AST literal-true/동일구문 비교 검색을 수행했다. 모든 파일의 의미나 모든 제어 흐름을 검증한 전수 감사가 아니다. 아래 후보만 소스 대조했고 CLI 합성 재현9개를 실행했다. 제품 구현·기존 시험을 수정하지 않았고 Docker/DB/CI/원격 실행0이다. migration DSN과 CAS fixture의 과거 실패는 원래 실패/오류였다. 세 선례 모두 실제 pass였다고 다시 표현하지 않고, 관측과 주장 범위 불일치라는 공통점으로 다룬다.

## 확인된 finding

### VB-AUDIT-01 / P2 / deployment_surface factory 오류와 대상 부재가 성공 처리됨

tools/deployment_surface.py:102~105는 factory 호출 중 TypeError를 필수 인자 부족으로, 다른 Exception을 설정 거부로 처리한다. :95~98의 없는 attr도 obtain 불가로 반환한다. verdict :199 부근은 obtainable=False이면 problems=[]이고 CLI는 exit0이다.

실측: 합성 factory 본문에서 ModuleNotFoundError, TypeError를 각각 발생시키고 없는 app attr도 지정했다. 세 CLI 모두 exit0/problems=[]였다. 동일 ModuleNotFoundError를 모듈 import 단계에서 내면 exit1/INCONCLUSIVE이다. 발생 위치만 옮겨도 미실행이 성공으로 바뀐다. 필수 인자를 요구하는 factory는 정상 대조군으로 exit0 유지됐다.

범위: 무설정으로 app을 얻지 못했다는 관측 자체는 사실이다. 하지만 내부 버그·lazy dependency 부재·잘못된 entrypoint를 의도한 설정 거부로 보증할 수 없다. 환경/구현 결함이 가려지는 검증 도구 결함이며 제품 인증 우회 실증은 아니다.

수정 조건: callable signature의 인자 결속 실패와 본문 오류를 분리하고, 대상 attr 부재/예상하지 못한 factory 예외는 판별 불가와 nonzero로 보고한다. 의도된 설정 거부는 명시적 계약/오류 종류로 식별한다. 원문 예외나 자격증명을 노출하지 않으면서 예외 범주·미도달 단계를 기록한다. 담당 Codex(검증 경계 수정), 독립 reviewer Claude. 이번 감사에서 수정/해소 처리하지 않음.

### VB-AUDIT-02 / P2 / 위조 Bearer probe 예외가 누락되어 exit0

tools/deployment_surface.py:177~178은 위조 토큰 요청 예외를 retried=None으로 바꾸고 기록하지 않는다. verdict의 probe-error/5xx 검사는 최초 무토큰 요청에만 적용된다.

실측: /v1/approvals가 무토큰에는401, 위조 Bearer에는 RuntimeError를 내는 합성 FastAPI 앱을 검사하면 최초401만 남고 exit0/problems=[]이다. 같은 앱이 위조 Bearer에200을 주면 exit1,403을 주면 exit0이다. 따라서 도구 전체가 실패 불가능한 것은 아니지만 위조 토큰 검사 미완료 경로가 성공으로 흐른다.

수정 조건: 재시도 status/exception을 별도로 기록하고, 예외/5xx는 판별 불가 nonzero로 판정한다. 401/403의 실제 거부, 2xx의 수용, 검사 미완료를 구분하는 회귀 시험을 추가한다. 기존 본문/비밀값 은폐는 유지한다. 담당 Codex, reviewer Claude. 미수정 finding이다.
