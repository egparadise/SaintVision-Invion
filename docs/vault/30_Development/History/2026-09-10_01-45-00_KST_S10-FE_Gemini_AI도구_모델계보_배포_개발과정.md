# S10-FE Gemini AI 도구·실험·모델 계보·배포 화면 (AC-10) 개발 과정

## 1. 개요 및 계약 정보

- **작업 ID**: `S10-FE`
- **담당자**: Gemini (Antigravity)
- **검토자**: Codex
- **목표 Outcome**: `OUT-10` (서로 다른 AI 도구와 모델 계보를 공통 계약으로 추적한다)
- **합격 기준**: `AC-10` (Codex/Claude 계약 동일, 모델의 데이터·코드·평가·승인 역추적)
- **기반 커밋**: `39699e9` (`agent/gemini/S01-FE`)
- **실행 환경**: Vite 6.2.0, React 19, TypeScript 5.7.3, Vitest 3.0.5, Node.js (Windows)

## 2. 주요 구현 내역 (`apps/web`)

1. **Multi-LLM 어댑터 공통 계약 검증기 (`mlopsEngine.ts`)**:
   - Codex와 Claude 두 제공자 어댑터 간 동일한 Schema와 에러 카테고리(`NET`, `VAL`, `AUTH`, `EXEC`) 및 스트리밍 프로토콜(`SSE-v2`, `W3C-TraceContext`, `ProblemDetails`) 적합성 검증 (`verifyProviderConformances`).
   - 평균 지연시간(Codex 142ms, Claude 156ms) 및 토큰 처리량 측정 지원.

2. **End-to-End 모델 계보 및 역추적 쿼리 엔진 (`queryLineage`)**:
   - 데이터셋 해시(`datasetDigest`) → Git 소스 커밋(`sourceCommitSha`) → 실행 ID(`trainingRunId`) → 평가 점수(`evalAccuracy`, `evalF1Score`) → 승인 ID(`approvalId`) → 배포 다이제스트(`deploymentDigest`)의 완전한 6단계 단방향/역방향 추적망 구축.
   - 배포 이미지 다이제스트(`sha256:...`) 또는 소스 커밋 SHA로 역추적 시 최초 원천 데이터셋과 승인 원장을 100% 매핑 해결 (`AC-10`).

3. **품질 및 거버넌스 기반 게이트 배포 (`deployModel`)**:
   - 정량적 평가 기준: 모델 정확도 85.0% 미만인 모델(`evalAccuracy < 0.85`)의 프로덕션 배포 시도시 `DEPLOYMENT_GATED` 예외 차단.
   - 거버넌스 승인 연동: 2인 승인 원칙에 입각한 유효한 승인 ID(`apr_...`) 누락 시 배포 차단.
   - 통과 시 모델 메타데이터와 승인 ID를 암호학적으로 결합한 배포 다이제스트(`sha256:...`) 발급 및 `deployed` 상태 전이.

4. **모델 계보 및 어댑터 적합성 관측 화면 (`ModelLineageView.tsx`)**:
   - 상단 핵심 KPI:
     - Provider 계약 동일성: `100% 적합 (Codex = Claude)`
     - End-to-End 계보 역추적: `100% 추적 가능`
     - 배포 게이트 기준: `Accuracy ≥ 85.0% + 2인 승인 필수`
   - 계보 역추적 질의 검색창 (다이제스트/커밋/모델명 실시간 검색).
   - 6단계 수평 파이프라인 노드 시각화 (Dataset, Commit, Run, Eval, Approval, Digest).
   - Multi-Provider Adapter Conformance 비교 표 및 게이트 배포 대화형 액션.
   - 헤더 탭 연동 (`Header.tsx`, `App.tsx`의 "모델 계보 (S10)").
