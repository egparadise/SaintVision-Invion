- **세 기준을 분리한다**: ① 로컬 검증(실제 실행·통과) ② 독립 검토 완료(sound 판정) ③ 운영 인수(실 운영 조건 수용). **하나로 합치지 않는다** — 기준별로 결과가 다르다.
- **시험 수 증가 ≠ 진척률**: 오늘 스위트가 ~1074 → ~1264로 늘었으나 이는 회귀 커버리지이지 완료율이 아니다. 완료율로 환산하지 않는다.
- **착지 ≠ done**: 브랜치 착지(`0955202`)만으로 항목을 done으로 올리지 않는다.
- **출처 표기**: `[Claude-실행]`(내가 직접 실행) / `[사용자-실행]` / `[Codex-실행]` / `[Claude-검토]`(소스 경로 검토, 런타임 아님) / `[미검증]`. **Codex가 직접 재실행/재검토하지 않은 항목은 위 표기로 남는다** — Codex가 인용 시 자기 확인이 아님을 알 수 있게.
