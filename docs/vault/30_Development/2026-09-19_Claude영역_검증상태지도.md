## 2. 미검증 — 그러나 미검증으로 정확히 기록됨 (제품 결함 아님, 도달 못 함)

### 2.1 Image lane 보안 단언 6건 (호스트 프로세스 생성 압박)

### 2.2 재실행 조건·명령 (환경 정리 후 이것으로 판별한다)

- **선행 조건**: 호스트의 **프로세스 생성 여유** 확보 — 동시 실행 Agent 수 축소, 그리고 OneDrive 핸들 압박 완화(측정 시 481,600, 2위의 60배; Obsidian vault가 OneDrive 동기 경로 AGENTS.md 45행). 이는 **사용자 환경 몫**이며 상관이지 확정 인과는 아니다.
- **재실행 대상/명령** (둘 중 하나):
  - image lane 러너: `python tools/run_vf_security_tests.py`(환경변수 `VF_TEST_IMAGE=saintvision-backend-candidate:vf-cx-01`). 증거는 `.work/vf-security.json`. host-init/timeout이면 `unverified`/exit 125로 기록.
  - 또는 pytest 직접: `docker_host` lane 포함으로 `test_server_container.py`를 실 candidate image·disposable DB로 실행(`INV_TEST_SERVER_IMAGE`, `INV_CONTAINER_TEST_DB_HOST`).
- **판별 기준**: 6케이스가 보안 단언에 **도달**해 pass/fail이 나오면 그때 처음으로 판별. 특히 business-kernel-role의 DB role 거부가 실제로 작동하는지. host-init/timeout이면 여전히 미검증(재차 환경 조치 필요).
- **착지와의 관계**: 이 6건 미검증은 **호스트 조건 문제이지 브랜치 착지 blocker가 아니다**(착지 판정과 운영 인수 판정을 분리 — Codex 합의). 착지는 완료됐고, 이 판별은 운영 인수 트랙이다.
