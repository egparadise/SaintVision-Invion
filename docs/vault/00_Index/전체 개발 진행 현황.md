# 전체 개발 진행 현황

**모든 Agent는 작업 시작 전에 이 페이지와 자신의 작업 페이지를 읽고, 작업 후 `작업한 것 → 확인한 증거 → 이어서 할 첫 행동`을 남긴다.** 긴 로그는 History/Evidence에 두고 이 페이지는 현재 상태와 다음 담당을 유지한다. 운영 방법은 [[Agent 지속 개발 운영 규칙]].
