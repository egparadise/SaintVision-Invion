처음 시작하는 순서

  1. 프로젝트 선택 — 일반 개발 또는 AI 학습 프로젝트를 고릅니다.
  2. Workspace 준비 — 사용할 도구의 작업 폴더를 만든 뒤 선택합니다.
  3. 도구 열기 — 원하는 기능을 설명하고 코드를 편집합니다.
  4. 작업 실행 — 단위 테스트, 프로그램 실행 또는 CPU 학습·평가를 누릅니다.
  5. 결과 확인 — 출력과 모델·평가 파일을 확인하고 내려받습니다.

AI 시작 프로젝트는 합성 데이터로 선형 모델을 학습하고, 학습에 사용하지 않은 행으로 평가합니다. 실제 데이터와 모델 코드는 프로젝트의 src·data에서 바꿀 수 있습니다.

웹 개발·대규모 모델·GPU 학습에 필요한 패키지는 프로젝트별 런타임으로 추가 검증해야 합니다. 현재 Python CPU 환경에는 표준 라이브러리가 제공됩니다.

SaintVision · 코드와 실제 실행 결과를 함께 관리합니다.
